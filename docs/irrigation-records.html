Interpretation boundary

Allocation is not measured water use

The input table assigns the same reported or planned allocation per hectare across farmer-years. It does not establish actual water delivered to each field, effective crop consumption, flooding duration, irrigation efficiency, drainage, seepage, percolation or runoff. The derived value per tonne changes only because realised yield changes. These records are retained as reporting evidence and were excluded as a foreground irrigation flow from the interpreted LCA.
