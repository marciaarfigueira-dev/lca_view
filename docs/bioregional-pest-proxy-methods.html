Pest-proxy methods

Explanation of how crop-protection records are converted into treatment-based pest, disease and weed intervention signals.

Methods note

Boundary

How to read the pest proxy

Back to overview Back to pest proxy

The pest proxy is derived from reported crop-protection interventions and target flags in the farm notebooks. It is not measured pest pressure. It does not verify pest abundance, economic thresholds, treatment necessity, avoided crop damage or treatment effectiveness.

Unit

Cell calculation

The default cell value is target-attributed active ingredient per farmer-year hectare. For each crop-protection operation, the applied active ingredient is assigned to each target flagged in the record. If several targets are flagged for one operation, the same application appears under each target. Target columns are therefore not additive totals.

Options

Metrics and filters

Option Meaning Interpretation
kg a.i./ha Target-attributed active ingredient divided by cultivated farmer-year area. Main land-based treatment signal.
kg a.i./t Target-attributed active ingredient divided by harvested paddy rice production. Output-normalised treatment signal mediated by realised yield.
Operation count Number of target-attributed crop-protection records. Frequency signal; does not account for dose or treated area.
Treated area / farm area Reported treated area divided by cultivated farmer-year area. Coverage signal; repeated passes and multiple targets can increase the apparent signal.
Year filter Shows all years together or a single production year. Colour scale remains fixed against the 2022-2024 maximum for the selected metric.
Target filter Limits the heatmap to one reported target. Useful for inspecting which farmer-years reported interventions against the selected target.

Colour Scale

Baseline for heatmap intensity

Heatmap colour intensity is scaled against the maximum farmer-year by target value across 2022-2024 for the selected metric. This means filtered views remain visually comparable across years. The scale is still within-sample: it is not a historical pest-pressure baseline or an external monitoring threshold.
