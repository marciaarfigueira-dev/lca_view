Environmental baseline methods

Explanation of the farmer-year LCA baseline view and how to interpret per-hectare and per-tonne results.

Methods note

Boundary

What this view shows

Back to overview Back to baseline

The baseline view summarises characterised EF 3.0 midpoint impacts for the 34 farmer-year observations. It is designed for comparative interpretation within the observed Sado rice sample, not for product certification, public farm ranking or formal sustainability classification.

Functional Units

Per hectare and per tonne

Per-hectare impacts describe modelled land-based pressure associated with recorded management. Per-tonne impacts express those same burdens relative to harvested paddy-rice output, so they combine land-based pressure with realised yield.

Panels

How to read the baseline page

Panel Meaning Interpretation
Impact basis by year Annual distributions of farmer-year impacts for the selected basis and midpoint category scope. Shows how the sample distribution changes by year, without attributing causes.
Sankey diagram Selected input source and component contributions for one impact category, year and functional basis. Shows where modelled burdens arise inside the selected LCA profile.
Mean source contribution Average contribution shares by input source within a selected impact category. Useful for dominant-driver interpretation, with caution where sources have close shares.

Cautions

Model and data limits

Results depend on farm-record completeness, product reconstruction, background-process proxies and foreground emission assumptions. Methane uses a common per-hectare flooded-rice parameterisation, while nitrogen-related emissions vary with reconstructed N inputs. Water-use results represent background-process water use embedded in retained inventories, not measured on-farm irrigation demand.
