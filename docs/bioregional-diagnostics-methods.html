PCA and DEA diagnostic methods

Explanation of the exploratory PCA and DEA options used in the thesis-facing diagnostic page. These methods are not used as farm rankings, causal estimates or compliance assessments.

Methods note

Boundary

How to read these diagnostics

Back to overview Back to diagnostics

The exploratory diagnostics use the same 34 farmer-year observations and four simple indicators: nitrogen input, crop-protection active ingredient, soil-operation intensity and yield. They are included to explore possible future analytical routes for larger or more complete datasets. The small availability sample means PCA clusters and DEA frontiers are sensitive to individual observations and should not be interpreted as stable farm types or environmental-efficiency scores.

Inputs

Variables used

Variable Meaning Interpretation limit
Nitrogen input Reconstructed fertiliser N input per hectare. Represents applied N, not crop uptake, surplus or measured loss.
Crop-protection intensity Active ingredient applied per hectare. Represents intervention intensity, not pest pressure or treatment effectiveness.
Soil-operation intensity Standardised machinery operation area per cultivated hectare. Represents operated area, not measured fuel use or soil compaction.
Yield Harvested paddy-rice output per hectare from cooperative records. Reflects realised productivity but is not causally attributed to the input indicators.

PCA / HCPC

Pattern-detection options

Option or output Meaning How to interpret it
PCA variant: uncapped Principal component analysis using the unmodified indicators. Shows raw multivariate contrast, but can be strongly influenced by extreme observations.
PCA variant: Winsor p90, p95, p99 Values above the selected percentile are capped before PCA. Tests whether the pattern changes when extreme values are dampened.
PC1 and PC2 The first two principal components summarising the largest contrasts among observations. Useful for visual pattern detection, not for assigning definitive farm types.
HCPC cluster Hierarchical clustering applied to the PCA space. Exploratory grouping only; cluster membership is sensitive in a small sample.
Silhouette Summary of how separated the exploratory clusters are. Higher values suggest clearer separation, but do not validate causal or agronomic classes.
ARI Adjusted Rand Index comparing cluster assignments across variants or leave-one-out checks. Used as a robustness signal: lower values mean cluster assignments change more strongly.
PCA loadings Contribution of each input variable to PC1 and PC2. Shows which indicators shape the plotted contrast.

DEA

Efficiency-diagnostic options

Option or output Meaning How to interpret it
Technical VRS Input-oriented DEA with variable returns to scale. Prototype technical input-output diagnostic using N, crop protection and machinery against yield.
Technical CRS Input-oriented DEA with constant returns to scale. Scale-sensitive comparison; useful as a contrast to VRS, not as a definitive score.
Non-CH4 climate-adjusted VRS Environmental sensitivity excluding methane because CH4 is common per hectare in the central LCA model. Tests one environmental framing without letting common methane dominate the frontier.
Selected-undesirable environmental VRS Prototype DEA including selected undesirable environmental burdens. Exploratory only; not a validated environmental-efficiency ranking.
Efficiency score Relative distance to the within-sample frontier under the selected model. Frontier is built from only 34 observations, so scores can change if observations or assumptions change.
Leave-one-out check Recomputes the diagnostic after excluding each observation from its own peer reference set. Shows sensitivity to individual observations and peer-set fragility.
