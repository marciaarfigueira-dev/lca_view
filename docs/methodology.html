Field Emissions

Methane from flooded rice cultivation

Direct methane emissions are modelled as foreground inventory flows using the IPCC Tier 1 emission-factor approach for flooded rice cultivation. Because the available records do not provide consistent farmer-level differences in water management, methane is treated as a constant hectare-based emission across farmer-years. Differences in tonne-based methane impacts arise from farmer-year productivity.

Parameter Symbol Value Unit Use
Baseline emission factor EFc 1.56 kg CH4 ha-1 day-1 Continuously flooded rice baseline.
Water regime during cultivation SFw 1.00 - Continuously flooded cultivation period.
Pre-season water regime SFp 1.22 - Applied uniformly across farmer-years.
Organic amendment scaling SFo 2.539 - Calculated as 1 + 0.19 x 8.1 and applied consistently.
Cultivation duration Days 130 days Fixed cultivation period.
Climate characterisation GWP100 CH4 28 kg CO2 eq kg-1 CH4 Used to convert CH4 to kg CO2 eq.
Seasonal methane CH4 628.19 kg CH4 ha-1 EFc x SFw x SFp x SFo x Days.
Methane impact CH4 CO2 eq 17,589.30 kg CO2 eq ha-1 Seasonal CH4 x GWP100 CH4.

Field Emissions

Nitrous oxide and urea CO2

Nitrous oxide emissions from managed soils include direct emissions from synthetic nitrogen, direct emissions from straw returned to the field, and indirect emissions from volatilisation and leaching/runoff. Synthetic nitrogen is separated into urea and compound fertiliser for volatilisation because the current workflow uses different volatilised fractions for these fertiliser types. Straw is included only as an emission-relevant residue input and is not treated as a co-product. Urea hydrolysis CO2 is added only for rows classified as urea.

Pathway Equation Constants and assumptions
Direct N2O from synthetic fertiliser N kg/ha x EF1 x 44/28 x GWP100 N2O EF1 = 0.003 kg N2O-N kg-1 N; GWP100 N2O = 273.
Direct N2O from straw 40.5 x 0.003 x 44/28 x 273 Fixed residue N returned = 40.5 kg N ha-1 yr-1; result = 0.191 kg N2O ha-1 yr-1, equal to 52.1235 kg CO2 eq ha-1 yr-1.
Indirect N2O from volatilisation N kg/ha x FracGASF x EF4 x 44/28 x 273 FracGASF = 0.30 for urea and 0.03 for compound fertiliser; EF4 = 0.01.
Indirect N2O from leaching/runoff N kg/ha x FracLEACH x EF5 x 44/28 x 273 FracLEACH = 0.30; EF5 = 0.0075.
CO2 from urea hydrolysis Urea-classified N kg/ha x 0.20 Applied only to fertilisation rows classified as urea in the current calculation pipeline.
Per tonne conversion Component per tonne = component per ha / productivity Productivity is farmer-year specific; this is why constant methane per hectare differs by tonne.
